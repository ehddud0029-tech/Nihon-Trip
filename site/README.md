# Nihon Trip 배포 안내

```
site/
├─ index.html       ← 사이트 화면 (PC·모바일 공용)
├─ areas.js         ← 지역·하위 지역 목록 (이름, 좌표)
├─ autoreserve.js   ← 맛집 목록 (AutoReserve 추천 순서 + 대표 메뉴·특징)
├─ google_picks.js  ← 오코노미야키·타코야키 인기 가게
└─ i18n/            ← 외국어 사전 (en.js 영어 · ja.js 일본어 · es.js 스페인어 · fr.js 프랑스어)
```

서버나 API 키가 필요 없는 정적 사이트예요. 관광지 사진(위키미디어)과 날씨(Open-Meteo)는 방문자 브라우저가 무료 공개 API에서 직접 불러옵니다.

## 올리는 방법 (무료, 둘 중 하나)

- **Cloudflare Pages**: https://dash.cloudflare.com → Workers & Pages → 만들기 → Pages → **에셋 업로드**에서 이 `site` 폴더를 끌어다 놓기.
- **GitHub Pages**: 이 폴더를 GitHub 저장소에 올린 뒤 저장소 **Settings → Pages**에서 `main` 브랜치를 선택.

## 맛집 (AutoReserve 추천)

- 하위 지역을 고르면 **라멘·스시 등 메뉴별 TOP 5**가 나와요(처음엔 라멘). 전체 메뉴 TOP 10은 상단 '추천 맛집 3곳'에만 쓰여요. 한 줄에 가게 하나씩, 옆에 **대표 메뉴 · 특징 · 예산** 칸이 있어요.
- 맨 아래 **추천 맛집 예약하러 가기** 버튼(상단 요약에서는 'AutoReserve에서 예약하기' 링크) 하나로 AutoReserve의 해당 지역·메뉴 페이지에 연결돼요(가게별 예약 버튼은 없음).
- 지역(예: 후쿠오카)을 고르면 첫 번째 하위 지역이 바로 선택돼요(지역 전체 칸은 없음).
- 순서는 2026년 10월 23일에 AutoReserve 지역·메뉴 페이지에 나온 순서 그대로예요. 순위는 바뀌니 가끔 새로 받아 오세요.
- 대표 메뉴와 특징은 Nihon Trip이 직접 짧게 정리한 글이에요(AutoReserve 소개문을 옮긴 것이 아님). 소개 정보가 적은 가게는 지역·장르·예산으로 정리했어요. 예산은 AutoReserve 가게 페이지 기준이고, 정보가 없는 곳은 "—"로 표시돼요.
- 오코노미야키·타코야키는 AutoReserve에 등록된 가게가 없어서 `google_picks.js`의 인기 가게로 보여줘요. 이때는 예약 버튼 없이 가게마다 **구글 지도 ↗** 링크만 달려요. 손꼽히는 가게가 없는 지역(하코네 등)은 '구글 지도에서 찾기' 버튼만 나와요.
  - `google_picks.js` 한 줄 = `[한국어 이름, 일본어 이름(구글 지도 검색어), 대표 메뉴, 특징, 예산]`
- 별점은 저장하지 않아요(구글 점수를 옮겨 적는 건 약관 위반이에요). 별점은 구글 지도 링크에서 확인해요.

### 고치는 법

`autoreserve.js`의 `AR_SHOPS`에서 가게 번호를 찾아 고치면 돼요.

```
"477":{"n":"하카타 스시 코우게츠","dish":"하카타 스시","feat":"현해탄 해산물 스시","b":"¥10,000~¥12,000"}
        이름                     대표 메뉴            특징                 예산
```

순서는 `AR_LISTS`의 번호 순서예요. 예: `"fukuoka/fukuoka-shi-hakata-ku":{"all":[474,475,...], "ramen":[...]}`

## 수수료 (AutoReserve 제휴)

수수료를 받으려면 AutoReserve 제휴(https://autoreserve.com/ko/for_affiliate)에 가입하고, 제휴 화면에서 받은 링크 방식에 맞춰 버튼 주소(`index.html`의 `arUrl`)를 바꾸세요. 링크 형식을 알려 주시면 바로 적용해 드릴게요.

## 관광지 사진

- 관광지는 많이 찾는 명소 위주로 모두 220곳이에요(교토 23곳, 시부야·롯폰기 11곳 등 하위 지역마다 3곳 이상).
- 사진은 각 관광지의 위키백과 문서 대표 사진(위키미디어 공용 등 자유 라이선스)을 방문자 브라우저가 불러와요. 저작자·라이선스와 원본 링크가 상세 화면에 자동으로 표시돼요. 지우지 마세요(라이선스 조건이에요).
- 구글·네이버 등에 올라온 사진은 저작권이 있어서 쓰거나 따라 그리지 않았어요. 직접 찍은 사진을 쓰고 싶으면 알려주세요.
- 사진 후보는 `index.html`의 `WIKI`·`SPOT_WIKI`에 있어요. `"ja:문서명"`은 일본어 위키백과 문서예요.

## 여행 추천 페이지 (첫 화면)

- 메뉴 맨 앞 **여행 추천**(휴대폰 하단 '추천')이 첫 화면이에요. 이달 평년 기온·여행하기 좋은 도시·여행 메모·인기 축제를 보여줘요.
- 아래 **지역 고르기**에서 보고 싶은 정보(관광지·축제·맛집·교통·쇼핑)를 먼저 고르고 하위 지역을 누르면 그 페이지로 이동해요.
- 관광지·축제·맛집·교통·쇼핑 페이지에서 '전체'를 누르면 그 주제의 설명(일본 문화·팁)과 지역 고르기가 나와요. 설명 글은 `index.html`의 `THEME_INTRO`에 있어요.
- 하위 지역을 고르면 상단 요약이 주제별로 바뀌어요. 관광지 페이지는 **날씨 · 관광지 TOP3 · 추천 여행 경로 · 시내 이동**이고, 교통 페이지는 날씨 · 공항에서 가는 법 · 교통카드 · 시내 이동이에요. 경로와 시내 이동 글은 `index.html`의 `AREA_GUIDE`에 있어요.
- 교통 페이지 아래 **교통카드 안내**(어디서 사는지, 지역별 카드)는 `IC_CARDS`에 있어요. 카드 사진은 위키미디어 공용 파일이에요(OKICA는 자유 라이선스 사진이 없어 이름으로 표시).
- 월별 추천 도시와 연결 항목은 `index.html`의 `MONTH_PICKS`, 월별 메모는 `MONTH_NOTES`에 있어요.

## 특산물·선물 추천 (쇼핑 페이지)

- 쇼핑 페이지 아래 **특산물·선물 추천**에 지역 선물 23가지와 파는 가게(구글 지도 링크)가 나와요. 고른 하위 지역의 것이 먼저, 빨간 테두리로 보여요.
- 목록은 `index.html`의 `GIFTS`에 있어요. 한 줄 = `[지역, 하위 지역, 종류, 이름, 일본어 이름, 설명, [[가게 이름, 구글 지도 검색어], ...]]`

## 외국어 (영어·일본어·스페인어·프랑스어)

- 상단 🌐 버튼에서 한국어 · English · 日本語 · Español · Français 중 하나를 고르면 페이지가 그 언어로 다시 열려요. 고른 언어는 주소의 `?lang=en`(ja·es·fr·ko)과 브라우저에 저장돼서, 다음에 와도 그대로예요. 이 주소를 그대로 공유하면 받는 사람도 같은 언어로 봐요.
- 데이터(`index.html`, `areas.js` 등)는 한국어 그대로 두고, 화면에 그려진 한국어 글자를 `i18n/언어.js` 사전으로 바꿔 보여주는 방식이에요. 그래서 한국어 내용을 고치면 사전에도 같은 문장을 넣어야 번역돼요. 사전에 없는 문장은 한국어로 남아요.
- 사전 파일 구조: `D`는 "한국어 문장 → 번역" 목록, `T`는 숫자·지역 이름이 바뀌는 문장 틀이에요. 예) `["{x} 시내 이동", "Getting around {0}"]` → '교토 시내 이동'이 'Getting around Kyoto'가 돼요. `{n}`은 숫자, `{M0}`은 달 이름이에요.
- 가게·관광지 이름: 영어는 영어 이름, 일본어는 원래 일본어 이름을 써요. 스페인어·프랑스어는 영어 이름을 그대로 써요.
- AutoReserve 예약 링크는 영어(스페인어·프랑스어 포함)는 `/en/`, 일본어는 `/ja/` 페이지로 연결돼요.
- 검색창은 한국어·일본어 이름과 함께 선택한 언어의 이름으로도 찾아요.
