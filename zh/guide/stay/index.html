行前准备

整理了去日本前最好了解的事项。规定和优惠可能会变化，出发前请再次确认官方信息。

入境准备花钱指南通讯住宿季节礼仪

住宿

住在哪个区域，会大大影响移动时间和旅行氛围。请比较各地热门住宿区域。

选住宿时的要点

  • 距离车站步行5–10分钟以内，带行李会轻松很多。请先在地图上确认最近的车站和出口。
  • 日本酒店房间偏小。如果有两个以上大行李箱，请务必确认房间面积（㎡）。
  • 东京、大阪、京都、福冈等地另收住宿税，请确认预订金额中是否已包含。
  • 樱花、红叶季和大型祭典期间，房间几个月前就会订满。日期确定后，请先用可取消的价格预订。

东京

第一次去的话，交通便利的新宿或东京站周边比较稳妥。

新宿
优点
线路最多的交汇点，还有机场巴士，到深夜都有很多吃喝玩乐的地方。
缺点
车站非常大且复杂，歌舞伎町一带晚上比较喧闹。
适合人群
第一次游东京、最看重交通便利的人
涩谷
优点
购物和潮流美食就在身边，步行可到原宿、表参道。
缺点
住宿费偏高，周末人非常多。
适合人群
喜欢购物和夜景的人
上野·浅草
优点
住宿相对便宜，前往成田机场的Skyliner从上野出发。
缺点
到涩谷、新宿等西部地区需要30分钟以上，晚上很早就安静下来。
适合人群
注重性价比、使用成田机场的人
东京站·银座
优点
前往新干线和机场都很方便，街道整洁，去箱根、镰仓一日游也方便。
缺点
住宿费较贵，晚上很多店会关门。
适合人群
经常去近郊、喜欢安静住宿的人

大阪·京都

很多人住在大阪，再一日游京都、奈良。如果在京都停留较久，住京都也不错。

难波·心斋桥
优点
从关西机场乘南海线直达，道顿堀美食就在眼前。
缺点
到深夜都很拥挤嘈杂，去京都比梅田稍远。
适合人群
第一次游大阪、以美食为主要目的的人
梅田（大阪站）
优点
JR、阪急、阪神线在此交汇，去京都、神户、奈良一日游都方便，百货店和餐饮街也多。
缺点
车站和地下街非常复杂，第一次去容易迷路。
适合人群
经常往返京都、神户的人
天王寺·新世界
优点
住宿相对便宜，关西机场特急Haruka在天王寺停靠。
缺点
夜晚氛围见仁见智，去北边的景点需要换乘。
适合人群
注重性价比、乘JR往返关西机场的人
京都站周边
优点
新干线和机场特急都停靠，还有巴士总站，带行李移动方便。
缺点
去清水寺、祇园等主要景点需要乘巴士或电车。
适合人群
行李多、在京都游览多日的人
河原町·祇园
优点
步行可到祇园、先斗町、锦市场，清晨还能看到宁静的街道。
缺点
住宿费较贵，旺季很难订到房间。
适合人群
想慢慢感受京都老街氛围的人

福冈

城市不大，住在博多、天神、中洲哪里都很方便。

博多站
优点
从机场乘地铁约5分钟，新干线以及前往由布院、别府的列车和巴士都从这里出发。
缺点
晚上的娱乐场所比天神、中洲少。
适合人群
行程较短、经常去近郊的人
天神
优点
百货店、地下街和美食云集的繁华街，前往太宰府的西铁电车从这里出发。
缺点
到机场和新干线车站比博多站稍远一些。
适合人群
喜欢购物和美食的人
中洲·春吉
优点
河边屋台和夜景就在眼前，位于博多和天神之间，去哪里都近。
缺点
夹杂着娱乐街区，晚上氛围有点杂乱。
适合人群
想享受屋台美食和夜间散步的人

北海道

很多人以札幌为据点，小樽当天往返，函馆、富良野则住一晚以上。

札幌站
优点
从新千岁机场乘JR直达，前往小樽、旭川的列车也从这里出发。
缺点
晚上吃东西的地方薄野一带要多得多。
适合人群
经常去近郊、冬天想少走雪路的人
薄野·大通
优点
拉面、成吉思汗烤肉、海鲜店云集，离冰雪节会场大通公园也很近。
缺点
这里是娱乐街区，部分地方到深夜都很吵。
适合人群
喜欢美食和夜生活的人
函馆站·港湾区
优点
离朝市、红砖仓库和函馆山缆车都很近。
缺点
去五棱郭、汤之川温泉乘路面电车需要20–30分钟。
适合人群
以函馆夜景和朝市为目的的人

冲绳

不租车的话多住那霸，租车的话很多人住中部或北部的度假酒店。

那霸（国际通周边）
优点
从机场乘单轨电车直达，餐厅和伴手礼店多，没有车也很方便。
缺点
离漂亮的大海和海滩有一段距离。
适合人群
不租车出行的人、行程较短的人
中部（北谷·宜野湾）
优点
可以在美国村前的海边看日落，去南部、北部都方便。
缺点
乘巴士出行不便，最好租车。
适合人群
自驾旅行、想同时享受海景和城市的人
北部（恩纳·本部）
优点
度假酒店门前就是清澈的大海，离美丽海水族馆和古宇利岛很近。
缺点
必须租车，住宿费较贵，距机场1个半小时以上。
适合人群
想在度假村放松的人、家庭旅行

名古屋·高山

名古屋住车站周边出行最方便；如果要去高山、白川乡，建议在高山住一晚。

名古屋站周边（名站）
优点
机场线、新干线和开往高山的特急都在这里停靠，带行李出行方便。
缺点
晚上的娱乐比荣少。
适合人群
经常近郊一日游、行程较短的人
荣
优点
离百货店、绿洲21、大须商店街很近，餐厅和酒吧很多。
缺点
从名古屋站还需要再换乘一次地铁。
适合人群
喜欢购物和夜间用餐的人
高山站周边
优点
老街和朝市步行10分钟可到，前往白川乡的巴士总站就在车站旁边。
缺点
店铺关门早，晚上很安静；旺季住宿很快就会订满。
适合人群
顺道游白川乡的人、想体验旅馆的人

广岛

很多人住在广岛站周边或市中心，宫岛则当天往返或在旅馆住一晚。

广岛站周边
优点
机场巴士、新干线和前往宫岛的JR都从这里出发，出行方便。
缺点
到和平公园乘路面电车约20分钟。
适合人群
要顺道去尾道、仓敷的人
八丁堀·本通
优点
步行可到和平公园，离大阪烧店和商店街也很近。
缺点
从车站带着行李过来需要乘路面电车或出租车。
适合人群
喜欢市区观光和晚餐的人
宫岛旅馆
优点
可以在一日游游客离开后的傍晚和清晨，看到宁静的神社。
缺点
住宿费较贵，晚上营业的餐厅很少。
适合人群
想度过特别一晚的人、情侣

四国

松山多住道后温泉或市中心，高松则多住靠近港口的车站周边。

道后温泉
优点
住温泉旅馆，可以穿着浴衣漫步到本馆和商店街。
缺点
从机场或JR车站乘路面电车需要20分钟以上。
适合人群
想享受温泉的人
松山 大街道
优点
离城堡缆车和商店街很近，有很多平价商务酒店。
缺点
没有温泉氛围。
适合人群
寻找高性价比住宿的人
高松站·港口周边
优点
前往直岛的船、琴电、机场巴士都很近。
缺点
夜间餐饮街在稍远一些的瓦町一带。
适合人群
跳岛游或去琴平一日游的人
